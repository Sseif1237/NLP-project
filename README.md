Introduction:
This report outlines the work conducted to solve a sequence-to-sequence NLP task using three different modeling approaches: Long Short-Term Memory (LSTM), Transformer, and a pretrained Transformer model (BERT). The aim was to evaluate the effectiveness of each model in terms of performance and computational efficiency. The dataset used for this project contains parallel sentences in English and French, making it suitable for tasks such as machine translation.
Comparison and Analysis:
The LSTM model demonstrated adequate performance on shorter sequences but faced challenges with longer dependencies. The Transformer model showed significant improvement, particularly in handling long-range relationships, thanks to its self-attention mechanism. BERT outperformed both models due to its pretrained contextual embeddings and fine-tuning capability, making it particularly suitable for the task.
Conclusion:
This project demonstrated the application of three different NLP models to a sequence-to-sequence task. While the LSTM model provided a strong baseline, the Transformer model showcased superior capability in handling complex sequences. LSTM emerged as the most effective model, achieving the highest accuracy. These results underscore the importance of pretrained models in modern NLP applications, particularly for tasks requiring deep contextual understanding
